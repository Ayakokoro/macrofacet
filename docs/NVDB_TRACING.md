# NanoVDB tracing

`macrofacet_experiments render` prepares a NanoVDB field before tracing. Procedural means are baked automatically. Imported fields use `field.mean_type: "nanovdb"` and `field.grid_file`. A baked file fixes sigma and its spatial coverage.

Field preparation bakes a certified density majorant grid and a direction-independent projected-area bound for the selected GP model. Both are reused by every path and rendering worker. DDA traverses density macrocells and proposes events from the cell's density bound multiplied by the prepared projected-area bound. An event is accepted using the actual Classic hazard. Cells with zero density are vacuum. This path handles both full-domain and surface-band fields; neither requires an optical-depth inverse.

The `density` grid stores the one-point height factor `phi(d/sigma)/(sigma Phi(d/sigma))`, where `d` is signed distance to the mean surface. The optional `alpha` grid supplies local Beckmann alpha when `field.use_alpha_grid` is enabled. In `local_tangent` mode, each point's material GP has a tangent-plane mean (value zero, unit normal gradient); for a generalized Gaussian NDF, each gradient component has variance `alpha(x)^2 / 2`. With GGX, the same grid value is used directly as GGX alpha. In `global_pointwise` mode, the alpha grid must be disabled; the gradient mean is the unnormalized `∇m(x)` and its covariance comes from the selected global kernel's zero-distance gradient covariance. Extinction multiplies the density by the projected area of the selected gradient distribution, which also supplies collision normals and scattering. `render_summary.csv` reports DDA candidate and null-collision counts. `resolved_config.json` records the selected GP model, prepared field, covariance, and `dda_null_tracking` sampler.
