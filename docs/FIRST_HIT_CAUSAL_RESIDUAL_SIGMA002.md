# 轻量逐段残差 GRU：sigma=0.02

本轮检查历史状态与因果输入是否能改善困难剖面和前缀一致性。沿用 [MLP 残差监督实验](FIRST_HIT_RESIDUAL_SUPERVISION_SIGMA002.md) 的数据与两个 MLP checkpoint 对照，增加轻量 GRU 及无历史对照。

后续已完成 [冻结 GRU 的条件梯度拟合实验](FIRST_HIT_CAUSAL_GRADIENT_SIGMA002.md)：九组梯度头训练支持历史状态改善梯度拟合。GRU 混合头相对旧 MLP 混合头的逐光线 PIT KS 均值下降 61.1%，晚碰撞处下降 69.7%；仍有少数剖面偏差，尚未进行完整渲染验证。

## 实测结论

**本轮支持继续使用轻量残差 GRU：历史状态改善了困难剖面的距离拟合，因果输入解决了共同前缀随未来输入变化的问题。** 这两项收益需要分别理解：无历史的因果头也满足前缀一致性，但距离精度明显落后于 GRU。

280 条固定测试光线的结果如下。神经网络指标先逐种子计算，再平均三个种子；“最坏光线”是逐种子最大误差的均值。平均最大误差指每条光线上 513 个查询点的最大绝对 T 误差，再对光线取均值。

| 方案 | 有效参数 | 平均最大 T 误差 | 最差 10% 均值 | 最坏光线 | 距离 NLL |
| --- | ---: | ---: | ---: | ---: | ---: |
| Local | 0 | 0.025339 | 0.104750 | 0.145240 | 0.712621 |
| 整段 MLP＋NLL | 57,632 | 0.018533 | 0.065584 | 0.248525 | 0.701130 |
| 整段 MLP＋L2＋T | 57,632 | 0.018605 | 0.063906 | 0.146387 | 0.699851 |

| **残差 GRU＋NLL** | **3,025** | **0.007633** | **0.020551** | **0.056371** | **0.692156** |

GRU＋NLL 相对上一轮 MLP＋L2＋T，平均最大误差下降 **59.0%**，最差 10% 均值下降 **67.8%**；三个种子各自均改善。相同损失下，GRU＋L2＋T 相对容量匹配无历史头，平均最大误差下降 **56.5%**。因此收益不能仅用参数量增加或损失变化解释，结果支持保留历史状态。

当前优先保留 **GRU＋NLL**：它在三个种子的验证 NLL 上均优于 GRU＋L2＋T，固定测试的平均与尾部指标也更好。这里仅比较了沿用 MLP 的 `eta=.01, beta=100`，不能据此否定其他正则或 T 监督权重。

## 前缀一致性与步长限制

第一种子、全部 280 条测试光线上的最大 T 变化：

| 操作 | MLP＋L2＋T | GRU＋NLL | GRU＋L2＋T |
| --- | ---: | ---: | ---: |
| 截断到 1/2，比较共同前缀 | 0.229718 | 6.75e-9 | 7.33e-9 |
| 截断到 3/4，比较共同前缀 | 0.172585 | 8.41e-9 | 7.68e-9 |
| 只修改后半段，比较前半段 | 0.032359 | 1.11e-16 | 1.11e-16 |
| 原三次片段四倍细分 | 5.63e-14 | 5.52e-14 | 5.53e-14 |

逐段状态推进与批量 GRU＋L2＋T 的最大 T 差为 **3.30e-8**。这些检查通过预设的 1e-5 阈值，与因果结构的预期一致。

**几何分段变化与 GRU 更新频率变化是不同操作。** 只在推理时改变 GRU 步长，第一种子 GRU＋NLL 的平均最大 T 误差从训练步长 `Δq=1/8` 的 0.00755，增加到 `1/16` 的 0.02889 和 `1/4` 的 0.02322。段长输入本身未能消除步长依赖。

当前模型用于后续渲染实验时，应固定内部 `Δq=1/8`，并缓存历史状态、分支累计 H 与入口先验。外部几何查询或追踪可采用不同分段，但需要保留尚未走完的内部区间，并仅在固定 q 边界推进 GRU。当前 Python 查询和状态接口验证了这一结构；尚未实现 C++ 追踪中的区间延续。若要改变 GRU 本身的更新尺度，需要另做多尺度训练与一致性实验。

## 实测成本与积分检查

以下计时查询两入口符号的整条 513 点 T 曲线，CPU 单线程，5 次重复取中位数；CUDA 使用 RTX 5090、batch=128。GRU 计时使用 `gru_T`，其结构与 `gru_nll` 相同。

| 方案 | CPU 已准备数据，µs/光线 | CPU 从三次剖面开始，µs/光线 | CUDA 已准备 batch128，µs/光线 |
| --- | ---: | ---: | ---: |
| MLP＋L2＋T | 335.10 | 2,772.26 | 7.50 |
| 容量匹配无历史头 | 183.12 | 4,187.97 | 3.60 |
| GRU＋L2＋T | 2,116.23 | 6,258.11 | 6.21 |

GRU 的参数量仅为原 MLP 的约 5.2%，但顺序推进使当前 CPU 已准备数据的整曲线查询慢约 6.3 倍；包含剖面处理和 local 积分时慢约 2.3 倍。当前 Python 的单次缓存状态更新及下一段修正约为 138 µs（两入口符号，不含 local 积分）。CUDA 批量微基准略快于 MLP，但未包含 VDB 访问、距离/梯度采样、C++ 调用和提前终止，不能直接当成渲染加速结论。

在 158 条验证光线上，积分步长减半并将求积阶数从 8 提高到 16，四个因果模型的最大 T 变化为 2.22e-16。新旧 local 积分在测试的 513 个点上差异也接近浮点误差，但这些点恰好落在旧 1024 格的边界；另用 4099 个验证查询点检查格内差异，最大值为 **0.001736**。因此报告明确区分积分离散与网络改进。GRU 和无历史头使用完全相同的积分实现。513 点经验曲线误差也不是整个连续区间的严格误差上界。

## 网络及对照

原始光线的几何分段中位数约为 400。新模型以固定的 `Δq=1/8` 推进，其中 `q=s/ell`，s 从介质入口计距。推进网格与光线总长度、原三次剖面的存储分段无关。

对于每个入口符号分支：

```text
h_0 = Initial(signed b(0), signed b'(0))
delta_i = Head(h_i, signed b(q_i), signed b'(q_i), log(1+q_i))
lambda(q) = lambda_local(q) * exp(delta_i), q 在第 i 个推进区间内
h_(i+1) = GRU(Encode(第 i 个已完成区间), h_i)
```

段编码包括该已完成区间的起点、中点、终点均值与导数，以及长度。**当前区间的残差只读进入状态和起点信息；区间末端只影响下一区间状态。** 输入中没有终点 Q、剩余长度或整段归一化位置 q/Q。

残差在每个推进区间内为常数，local hazard 仍随该处的均值与导数变化。两个符号分支共享权重，入口符号概率保持解析定义。输出层零初始化，使初始分布等于 local。

| 新方案 | 历史状态 | 有效参数 | 损失 |
| --- | --- | ---: | --- |
| local_head_T | 固定入口编码 | 993 | NLL＋L2＋T |
| local_matched_T | 固定入口编码 | 3,009 | NLL＋L2＋T |
| gru_nll | 16 维 GRU | 3,025 | NLL |
| gru_T | 16 维 GRU | 3,025 | NLL＋L2＋T |

GRU 的段编码维数为 16，残差头宽 32。容量匹配的无历史头宽 128。无历史实现仍分配了供初始化配对用的 GRU/段编码参数，但不会执行这些模块；表内列的是参与计算的有效参数。原整段 MLP 为 57,632 个参数。

四个方案各训练三个种子，共 12 组，每组 500 epochs。种子为 20261015、20261016、20261017；批量、抽样顺序、优化器与学习率调度相同。三个主实验方案同种子初始参数完全相同。容量匹配方案改变了头宽，不能宣称所有初始权重与小头相同。

## 数据、损失与数值积分

复用 `outputs/fields/shader_ball_full_0.02.nvdb` 对应的多视角数据：695 条训练光线、158 条验证光线、280 条固定测试光线。训练和验证每条 2048 次参考实现，测试每条 8192 次，全部保留逃逸样本。

参考标签仍为 H=1、B=8、步长 1/64 的 GPIS function-space Tungsten-linear 采样；本轮没有新采集标签，网络输入仍为保存的连续三次均值剖面。

组合损失沿用上轮权重 `eta=0.01, beta=100`。每轮每条光线抽 512 个实现计算条件删失 NLL；透射率 MSE 使用全部训练实现生成的 513 点经验曲线。残差 L2 按每个推进区间的真实宽度/Q 加权，避免最后一个短区间被过度惩罚。

每个训练都按最低验证边缘距离 NLL 选 checkpoint。所有方案确定后再评估固定测试；容量匹配对照在观察首个种子的验证结果后加入，未使用本轮测试指标调参。该固定测试集已用于前轮诊断，仍是同一场景，不构成新场景盲测。

local hazard 公式沿用原实现。积分区间在原三次剖面边界和 1/64 的固定 q 网格处分裂，每段使用 8 点高斯求积。查询处的剩余积分只积分到查询点，避免截短光线时改变过去的积分网格。

训练前缓存与网络无关的 local 区间质量、查询处部分质量及 log hazard。网络只预测残差倍率并组合累计量，因此不需要通过 ODE 求解器推进神经状态。新旧积分离散的差异在报告中单独检查。

## 一致性检查的含义

- 截断至原长度的 1/2 或 3/4：相同前缀的透射率应保持一致，包括截断落在推进区间内部的情况。
- 保持总长度，只改后半段：前半段预测不应改变。
- 将每个原始三次片段细分为四段：保持同一均值函数，固定 q 推进网格不变。
- 逐段延续状态与批量 GRU：同时保留隐藏状态、两符号分支累计 H 和入口先验，结果应一致。
- 推进步长改为 1/16 或 1/4：这是改变 GRU 状态更新频率，不属于上述几何重分段检查；单独报告误差变化，不重训或按测试结果选步长。

前缀一致性由输入结构保证，不代表模型已经准确拟合参考首碰分布。距离精度、步长敏感性和运行成本需要分别看结果。
