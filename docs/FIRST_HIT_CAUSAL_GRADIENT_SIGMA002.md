后续的 [梯度头步长精度测试](FIRST_HIT_CAUSAL_GRADIENT_STEP_SIGMA002.md) 已完成五种内部步长、三个种子的评估。Mixture 头在半步长和双倍步长下，逐光线 PIT KS 分别变为训练步长的 2.06、1.85 倍；CDF 同样敏感。第一种子的状态/位置消融将主要变化定位到历史状态，当前渲染接入应保持内部 Δq=1/8。

## 实测结论

**历史状态同时改善了条件梯度拟合；当前继续使用 GRU＋混合分布头，CDF 保留作对照。** 九组训练均已完成，三个种子中混合头的验证及测试条件 NLL 均略优于 CDF。该结论限定在冻结主干、相同 150 epochs 预算和当前数据上。

下表是三个种子各自计算指标后的平均值；所有指标以小为好。逐光线统计按至少 64 次命中的门槛保留 220 条光线。旧 MLP 也按同一门槛重新汇总，因此其逐光线均值与上一份使用全部有命中光线的报告略有不同。

| 方案 | 条件速度 NLL | 全局 PIT KS | 逐光线 PIT KS 均值 | P95 光线 PIT KS | 晚碰撞 PIT KS |
| --- | ---: | ---: | ---: | ---: | ---: |
| 原 MLP＋Mixture | 1.257781 | 0.002197 | 0.034663 | 0.091608 | 0.043979 |
| 原 MLP＋CDF | 1.259126 | 0.002866 | 0.034762 | 0.087470 | 0.058855 |
| 无历史＋Mixture | 1.259278 | 0.002056 | 0.028951 | 0.076249 | 0.072223 |
| **GRU＋Mixture** | **1.229802** | **0.001680** | **0.013472** | 0.029507 | 0.013313 |
| GRU＋CDF | 1.230627 | 0.001917 | 0.014586 | **0.029430** | **0.012798** |

GRU 混合头相对旧 MLP 混合头，条件 NLL 减少 **0.027979 nat/命中**，逐光线 PIT KS 均值下降 **61.1%**，最差 10% 光线的 PIT KS 均值从 0.098900 降至 0.035060，晚碰撞区域 PIT KS 下降 **69.7%**。

相同容量与初始化下，历史混合头相对无历史头的条件 NLL 减少 **0.029476**，逐光线 PIT KS 从 0.028951 降至 0.013472，支持历史信息的作用。两个新 mixture 头各 7,064 参数，CDF 头为 7,194 参数；冻结的距离 GRU 另有 3,025 参数。

CDF 与 Mixture 的差异远小于有无历史的差异：CDF 的总体 NLL、平均逐光线 PIT 略逊，但晚碰撞与 P95 略好。晚碰撞 PIT 的种子标准差分别约为 Mixture 0.00511、CDF 0.00319，不能仅凭二者均值约 0.00051 的差距宣称 CDF 更优。

![梯度拟合比较](../outputs/first_hit_causal_gradient_sigma002_20261016/gradient_fit.png)

总体校准较好，但总体指标确实会掩盖局部误差。例如无历史头的全局 PIT KS 也只有 0.00206，晚碰撞处却达到 0.07222。GRU 混合头的 68%/90% 区间覆盖率分别为 **68.04% / 90.03%**；这仍需结合逐光线、位置分组指标理解。

## 条件采样与因果检查

第一种子在每个参考首碰位置各生成一个梯度速度样本，每个方案共 **1,679,081** 个。与参考速度 CDF 比较，在由训练数据确定的六个速度阈值上，逐光线最大 CDF 误差均值为：旧 MLP 混合头 **0.028717**，无历史头 **0.022933**，GRU 混合头 **0.008391**，GRU CDF **0.009346**。该比较固定了参考位置及入口符号，不包含距离采样误差。

GRU 混合头和 CDF 采样自身的 PIT KS 分别为 0.000674、0.000637，支持采样器遵循网络输出；这与网络是否拟合参考分布是两项不同的检查。

全部 280 条测试光线上，对两个入口符号、33 个查询位置和六个速度阈值检查前缀截断、只改未来和剖面重分段。三个新头的最大 CDF 变化为 **8.35e-7**，通过 1e-5 阈值。这个检查包含低概率符号分支和非实际命中位置，用于检验结构，不能解释为渲染平均误差。当前内部 GRU 步长仍固定为 1/8。

## 拟合对象与公平对照

学习的变量是正的无量纲纵向首碰梯度速度：

```text
W = -k * (ell / sigma) * dot(omega, g) > 0
p(W | 首碰位置 q, 入口符号 k, 截至 q 的均值剖面)
```

梯度头在参考首碰位置上训练和测试，以隔离距离预测误差。这里的分开研究仍保留位置和历史条件，不假设距离与梯度相互独立。完整三维梯度、法线及渲染不在本轮验证范围内。

数据与上轮相同：sigma≈0.02 的 shader ball，695 条训练、158 条验证、280 条固定测试光线；训练/验证每条 2048 次参考实现，测试每条 8192 次。标签来自 H=1、B=8、步长 1/64 的 GPIS function-space Tungsten-linear 采样。未修改、补充或重新分配标签。

冻结每个配对种子的 `gru_nll` checkpoint，接三个新方案：

| 方案 | 条件信息 | 分布表示 |
| --- | --- | --- |
| mixture_local | 固定入口状态＋当前位置局部信息 | 8 分量截断高斯混合 |
| mixture_gru | GRU 历史状态＋当前位置局部信息 | 8 分量截断高斯混合 |
| cdf_gru | GRU 历史状态＋当前位置局部信息 | 8 区间单调样条 CDF |

头宽均为 64，输入状态为 16 维。两个 mixture 方案同种子全部初始权重一致，只有是否读取推进后的历史状态不同；CDF 与 mixture 的隐层初始化一致，输出初始化按分布定义不同。

三个种子为 20261015、20261016、20261017，每个方案训练 150 epochs，每轮每条光线抽 512 个参考实现。抽样顺序和优化设置与旧梯度实验一致，仅命中样本贡献梯度损失，逃逸样本不具有梯度标签。

新头的局部输入为区间内进度、log(1+q)、带入口符号的均值与导数，不含终点 Q 或 q/Q。历史状态只包含已完成区间，查询落在状态边界时采用左极限，保证截断和继续光线时使用一致的上下文。

复用旧整段 MLP 的 Mixture/CDF checkpoint 作现有方案对照。旧头输入 32 维全局编码，也能读取未来剖面；因此历史作用主要通过两个同容量的新 mixture 头判断，不能把与旧 MLP 的差异全部归因于一种因素。

## 指标解释

条件速度 NLL 按命中数加权；PIT 使用 `F_pred(W_reference)` 检查分布校准，理想情况接近均匀。除全局 PIT，还统计逐光线 PIT、位置分组和 68%/90% 区间覆盖率。

逐光线汇总只使用至少 64 次参考命中的光线，减少低样本数的影响；这个条件在训练前固定。晚碰撞定义为 q/Q≥3/4，q/Q 只用于评估分组，不进入新网络。

条件 CDF 图在相同的参考首碰位置和符号上平均预测分布，再与这些位置的经验速度分布比较，不能解释成单个精确位置的无噪声真值。条件采样也保持参考位置固定，用于检查梯度头及其采样器，未生成新的首碰距离。

## 实现与复现

完整流程：

```powershell
python -B python/first_hit_se_cli.py causal-gradient --config python/configs/first_hit_se_causal_gradient_sigma002.json
```

可用 `--phase train/evaluate/diagnose/report` 分阶段运行。九组训练全部完成后才评估固定测试集；每组 checkpoint 只按验证条件 NLL 选择。已完成训练可复用，未完成训练可从 `latest.pt` 恢复；修改锁定配置或训练源码须更换输出目录。

新 checkpoint 格式为 `first_hit_causal_gradient`，位于 `outputs/first_hit_causal_gradient_sigma002_20261016/runs/<variant>_<seed>/best.pt`，通过 `causal_gradient_study.load_head` 载入，并配合对应种子的冻结 `gru_nll` 距离模型。

20 项数值及回归测试通过：

```powershell
python -B -m unittest python/tests/test_causal_gradient.py python/tests/test_gradient_cdf.py python/tests/test_causal_residual.py -v
```

覆盖缓存与距离状态一致、边界处的前缀一致性、历史消融、符号对称、冻结权重、无命中光线、CDF 归一化与逆采样。距离训练实现、数据及旧 checkpoint 保持不变。
